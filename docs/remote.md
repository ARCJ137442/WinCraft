# 非本机提供者：首版安全隧道路径

协议没有依赖调用者 PID 或本机内存地址，提供者可以位于另一台机器。首版网络服务仍只监听 loopback，这是传输部署限制，不是产品永久限定。

## 使用方式

在提供者机器上，通过已配置的 SSH 服务连接到承载窗口的机器，把提供者机器本地端口转到窗口宿主的真实端口：

```text
ssh -N -L 17960:127.0.0.1:<窗口宿主实际端口> <用户>@<窗口宿主机器>
```

由用户安全传递当前宿主描述文件给该受信任提供者，保留 host_id/token，并覆盖连接地址：

```powershell
python examples/python/focus_demo.py --runtime "<受保护的描述文件副本>" --ws-url ws://127.0.0.1:17960/v1/ws
```

调用方会校验 hello 返回的 host_id 与描述文件一致。令牌仍是秘密，SSH 不代替世界级授权；不要把文件上传到公共存储。

本包未建立 SSH 服务、未操作防火墙、未执行远程连接。此部署链路需本地测试。正式 LAN/TLS、多设备发现、身份配对和授权撤销放到后续安全设计；不要通过放宽 Origin 或绑定 0.0.0.0 代替它。
