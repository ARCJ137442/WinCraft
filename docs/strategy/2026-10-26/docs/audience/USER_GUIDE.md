# 用户层：世界、来源与控制权

**世界**是你能看见和操作的界面空间，目前对应一个桌面窗口。**提供者**是送来内容并处理操作的应用或程序。WinCraft负责窗口，不替来源保存另一份任务或笔记。

连接一个来源不会自动允许它接管所有窗口。你可以只看、允许它编辑自己区域，或者由本机管理器接管。当前原型仍以整窗单写租约为基础；“各改一块”的能力属于后续计划。

配方/整合包保存布置与需要的能力。它不保证另一台机器上有同样的软件。打开后先显示“能用什么、缺什么、要什么权限”，你确认后再创建本次资源；旧授权不随包一起复制。

遇到窗口遮挡、穿透或隐藏时，用托盘管理器找回。来源离线时，保留的数字不代表仍是实时；等待你选择的问题可以取消，取消不是执行失败，也不是默认同意。

当前可用功能以产品对应版本的用户指南和能力表为准。本包是后续计划，不是安装说明。
