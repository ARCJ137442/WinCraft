# 教程世界与自用：先让人会玩，再让人会写

## 目标

设置、管理器和新手教程都是普通世界，通过通用组件与动作构建；可信 operator 的授权例外必须明确，不能让“同一通路”变成高权接口公开。

## 五课体验

| 课程 | 用户做什么 | 原语与验证 |
|---|---|---|
| 看见第一个世界 | 创建、拖动、隐藏、找回 | 窗口与生命周期；全部为教学数据 |
| 搭一块会变的方块 | 修改文字/进度、替换节点 | 动态 scene 与数据绑定，不写前端 |
| 与程序对话 | 点选、输入、取消 | interaction/result；取消不是失败 |
| 换一个自己的外观 | 中英切换、字号与主题 | i18n、主题优先级、可访问性 |
| 邀请已有程序 | 从授权 inventory 选来源 | 发现/授权分离、缺失来源可解释 |

教程使用独立标记的 world/scope/Provider。退出时只清理自己创建的世界与资源，不清除用户世界、不改真实笔记或发请求到生产服务。用户可以跳过，教程不成为每次启动的阻塞流程。

## 逐层文档

用户指南讲“连接/看见/操作/找回”；Provider 指南讲声明、数据、动作、断线；内核指南讲资源、租约、版本、因果和清理。三份术语映射到同一模型，不能新手版说“永久归你”专业版却是 15 秒租约。

Agent skill 教的是公开能力、错误恢复和能力查询，不是隐藏后台命令。完成一课能导出一个无凭据的示例，以人可读、程序可验、Agent 可修改的格式存在。

## 当前实现切片

`examples/python/provider_tutorial.py` 已提供真实协议上的五课合成教程：创建/隐藏找回、动态插入组件、静态动作与回执、有限主题 token、`world.list` 元数据与加入策略。它只创建普通邀请世界，不申请 operator 身份；退出只销毁本脚本创建的世界。发现课仅保留计数，不读取其他世界 scene，也明确协议 0.3 没有独立提供者目录。

五课的组件/schema 与普通 Rust headless 的创建、首屏更新和清理已通过验证；完整 Tauri 窗口互动、拖动/隐藏/找回、实际 UIA 与读屏仍待旧宿主关闭后的原生验收。当前切片不实现整合包、真实来源授权 inventory、教程导出或国际化课程内容。
