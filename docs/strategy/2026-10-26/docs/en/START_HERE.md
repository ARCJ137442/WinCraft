# WinCraft evolution handoff — English entry

This is a design and execution handoff, not a runtime release. The Chinese documents are the authoritative decision record for this delivery. These English pages are entry points, not a claim of complete translation.

WinCraft is a composable interaction runtime for people, programs and agents. Windows floating windows are the first carrier. Keep Rust/Tauri, the trusted renderer, provider-owned business truth, revocable leases and local human takeover.

Configuration packs preserve layout, capability requirements and adaptation intent. They do not bundle providers, copy credentials, inherit grants or guarantee the same software on another machine. Discovery is not permission. An adaptive program is separately approved and produces a proposed plan; importing a pack never executes it implicitly.

First implement a compatible Popup-Ask transport. Preserve cancellation, Other/notes, original language and output contracts. A long human decision wait is not the host's ten-second interaction acknowledgement.

Follow [the integration guide](../../INTEGRATION.md), [the task index](../../plan/TASKS.md), and [the evidence baseline](../00_BASELINE_AND_EVIDENCE.md). New schemas are proposals, not protocol 0.3 additions. Do not publish, relicense or access real private data without the relevant authorization.
