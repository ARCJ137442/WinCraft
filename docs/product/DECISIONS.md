# 决定账本

日期：2026-10-25。本文区分用户已经决定、AI 本轮实施取舍和尚未实现，不把讨论过视为验证通过。

## 用户已确认

| 决定 | 对实现的约束 |
|---|---|
| 世界就是窗口 | UUID 寻址一个窗口实例；不暗含永久存档 |
| 业务状态外置、运行状态可重建 | 宿主不维护外心计时/任务/笔记的另一份权威业务状态 |
| 多读单写，先窗口再组件 | 首版整个世界只有一个活动写租约；其他会话只能看不可变快照 |
| 无固定绑定/常客 | 加入、租约、动作路由仅在内存中；断线即清理会话 |
| 宿主托盘化、管理界面自用 | 不需常驻主窗口；管理器是内部提供者生成的世界 |
| 调用者不用前端技术 | 外部只传声明、数据与事件回执；不上传脚本、网页源码 |
| Rust；最多 Tauri WebView | 不采用 Go/Electron，也不为每个提供者启动网页环境 |
| 连接后继续搭建 | 支持运行中增加、移除、替换、重排组件，不限第一次注册 |
| 窗口可交给人类，也可由程序控制 | 默认 human 几何模式允许用户调整窗口宽度与尺寸；provider 几何模式由提供者控制；本地管理器保留明确接管入口 |
| 悬浮窗按实际内容呈现 | 默认依据 renderer 实际布局高度安排原生窗口高度；宽度调整后保留用户宽度并按新布局重算高度；页面/窗口级滚动条默认隐藏，超出显示器可用高度时只在内容区内部保留滚动访问 |
| 仪表盘文本不应撑破窗口 | 长文本在组件可用宽度内自然换行；不能横向溢出或让布局反复震荡；内容变化后高度测量应收敛，长内容仍能访问 |
| 右键交互遵循显式注册 | 默认阻止 WebView 原生上下文菜单；仅静态注册 `context_action` 的交互组件响应右键，并把已注册动作交给当前提供者 |
| 隐藏与销毁是不同操作 | 标题栏最小化只隐藏窗口并保留世界/租约；关闭按钮可销毁普通世界；快照暴露 `visible`，provider 可用 `window.configure` 恢复显示，管理器也能重新呈现隐藏世界 |
| 标题栏与指针穿透显式配置 | 标题栏默认显示且固定在可滚动工作区外；provider 可切换标题栏显示，click-through 默认关闭且 provider 可配置；隐藏标题栏后本地接管/找回入口仍可恢复 |
| 悬浮工作面默认半透明 | 默认 `surface_opacity=0.8`，窗口保持原生透明背景；provider 可读取快照并用 `window.configure` 调整该值 |
| 世界管理器超长内容 | 管理器固定窗口壳与工具栏，工作区在高度受限时内部滚动，滚动不改变世界或 provider 状态 |
| 不限本机提供者 | 协议身份不使用本机 PID 作安全依据；远程传输需有鉴权与保护 |
| 从外心悬浮工作台代码出发 | 固定源快照、保留许可证与迁移说明；不复制外心业务状态机 |
| 立即交付源码和文档给 Codex | 不再用新一轮需求问卷代替实施 |

## 本轮 AI 实施取舍（不是用户额外确认）

- 对外使用单一 WebSocket 双向数据通路；HTTP 仅用于 health/discovery。协议保留版本/能力握手，不假装实现了多通道动态升级。
- 默认 loopback 随机端口；安全隧道支持非本机提供者；不实现原生 TLS/LAN 监听。不是永久产品限制。
- 运行时 token 每个宿主随机生成；每个世界可为受邀或对已鉴权会话开放。
- 写权限是 15 秒可续租的运行时租约。每次更替有 epoch；它不是 Rust 编译器跨进程借用。
- 默认窗口几何交给人类。提供者主动切换到 provider 模式后才可设置位置/尺寸；人类接管会撤销租约并设置 operator hold，直到本地解除。
- 宿主暂存输入草稿、IME 组合、操作等待状态、窗口几何与组件树，不保存业务数据库。
- 首批 10 个组件；前端采用无框架 TypeScript，而非搬入整个外心 React 应用。Tauri 原生窗口与外心窗口模式保留。
- 限制 16 个世界（包含内部管理器）、每世界 256 节点/深度 16、单消息 256 KiB，以便先验证完整链路。
- 管理器为进程内可信提供者，与外部同用 Engine/Scene/事件语义；它有明确的本地操作员权限，不要求绕本机 WebSocket 自发 HTTP。
- 协议接受表示权威模型已更新，不保证 OS 已应用；native report 单独说明成功/失败。
